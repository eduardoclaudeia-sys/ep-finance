# EP Finance V1.7 — Patch seguro

Este pacote foi feito para **não apagar nem reformatar os dados existentes** da V1.6.2.

## Regra principal
O objeto atual continua usando as chaves já existentes:
`transactions`, `bills`, `goals`, `investments`, `settings`.

A V1.7 acrescenta somente `v17` e metadados opcionais nas movimentações novas.

## Arquivos para adicionar ao repositório
Copie para a raiz:
- `v17-data.js`
- `v17-import.js`
- `v17-quotes.js`
- `v17-security.js`
- `v17.css`

Copie a Edge Function para:
- `supabase/functions/investment-quotes/index.ts`

## Carregamento no index.html
Depois dos arquivos já existentes do app, carregue os módulos V1.7 nesta ordem:

```html
<link rel="stylesheet" href="v17.css?v=1.7.0">
<script src="v17-data.js?v=1.7.0"></script>
<script src="v17-import.js?v=1.7.0"></script>
<script src="v17-quotes.js?v=1.7.0"></script>
<script src="v17-security.js?v=1.7.0"></script>
```

## Integração no app.js
Logo depois de carregar o JSON financeiro do usuário, normalize sem destruir nada:

```js
financeData = EPV17Data.migrate(financeData);
```

### Parcelamento
```js
const result = EPV17Data.createInstallments(financeData, transactionBase, 12);
financeData = result.data;
await save/sync usando a mesma função atual do seu app;
```

### Recorrência
```js
const result = EPV17Data.createRecurring(financeData, transactionBase, {
  frequency: 'monthly', // weekly | monthly | yearly
  count: 12
});
financeData = result.data;
await save/sync usando a mesma função atual do seu app;
```

### Importar OFX
```js
const parsed = EPV17Import.parseOFX(fileText);
const preview = EPV17Import.preview(financeData.transactions, parsed);
// Exiba preview, permita marcar _skip e só então:
const result = EPV17Import.merge(financeData, preview);
financeData = result.data;
await save/sync normalmente;
```

### Importar CSV
Troque `parseOFX()` por `parseCSV()`.

### Cotações
Depois de publicar a Edge Function `investment-quotes`:

```js
const tickers = financeData.investments.map(i => i.ticker).filter(Boolean);
const quotes = await EPV17Quotes.fetchQuotes(supabase, tickers);
financeData = EPV17Quotes.applyQuotes(financeData, quotes);
await save/sync normalmente;
```

O valor manual existente permanece como fallback se a cotação falhar.

### Biometria / Face ID / Touch ID
Use WebAuthn/passkeys. No iPhone, quando suportado, o sistema usa Face ID/Touch ID de forma nativa.

```js
const registration = await EPV17Security.register(user.id, user.email);
financeData.v17.security.credentialId = registration.credentialId;
financeData.v17.security.enabled = true;
await save/sync normalmente;
```

Para desbloquear:

```js
await EPV17Security.unlock(financeData.v17.security.credentialId);
```

> A biometria protege a abertura local do app. Ela não substitui o Supabase Auth.

## Supabase — preservação dos usuários
Não execute `DROP`, `TRUNCATE`, `DELETE` ou recriação de `finance_data`.
A V1.7 não exige nova tabela para parcelamento/recorrência/importação/biometria.

A Edge Function de cotações é independente e não grava no banco.

## Service Worker
Atualize somente o identificador de cache da sua versão atual para algo como `ep-finance-v1.7.0` e inclua os 5 novos arquivos nos assets. Não remova rotinas de push já existentes da V1.6.2.

## Checklist antes do merge na main
1. Fazer backup de um usuário pelo recurso JSON já existente.
2. Testar login e sync.
3. Conferir se movimentações antigas continuam aparecendo.
4. Criar uma compra 3x e conferir datas/valores.
5. Criar recorrência mensal.
6. Importar OFX/CSV e validar duplicatas no preview.
7. Testar cotação com ticker cadastrado.
8. Testar desbloqueio por passkey em HTTPS/PWA.
9. Só depois enviar para `main`.
